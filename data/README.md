# Data Workspace

**Primary dataset:** Government Grants Register 2024–25 — scheme and award data  
**Publisher:** Cabinet Office  
**Format:** ODS  
**Official source:** https://www.gov.uk/government/statistics/government-grants-statistics-2024-to-2025

Use a frozen Mettelo cohort version/reference so the project remains reproducible if the publisher changes its site. Preserve raw data unchanged and record version/acquisition details in `SOURCE_REGISTER.md`.
