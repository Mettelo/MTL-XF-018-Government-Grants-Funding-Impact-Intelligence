# MTL-XF-018 — Government Grants Portfolio, Funding Concentration & Programme Intelligence

**Mettelo Project Studio — Cross-Functional Delivery Series**

| Field | Detail |
|---|---|
| Client | Confidential National Grants & Programme Directorate |
| Sector | Public Sector / Grants / Programme Management |
| Duration | 8 weeks |
| Recommended team | 6–8 |
| Sponsor | Director of Grants Management |
| Engagement | Simulated confidential-client engagement |

Leadership oversees a large grants portfolio but lacks a consistent view of award concentration, recipient dependence, programme overlap, geographic distribution and whether funding patterns align with strategic intent.

**Commissioned decision:** Where should grant-management teams investigate concentration, duplication, under-reach or portfolio imbalance before the next funding cycle?

This is an end-to-end multidisciplinary engagement, not a dashboard-only exercise.

Start with the project, governance, data and submission documents in this repository. Each team creates its delivery repository under the **Mettelo GitHub organisation** and adds every team member using their individual GitHub account.
