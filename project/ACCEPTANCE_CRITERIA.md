# Agreed Acceptance Criteria

1. **AC1:** Award totals reconcile to the selected source scope after quantified exclusions.
2. **AC2:** Recipient-name standardisation preserves a match log and never silently merges ambiguous entities.
3. **AC3:** At least one concentration metric is calculated both by value and award count.
4. **AC4:** Potential overlap flags are labelled for investigation and are not described as duplication without supporting evidence.
5. **AC5:** No dashboard or briefing uses funding value as a proxy for programme impact.
6. **AC6:** Geographic analysis states whether geography represents recipient, delivery or another available location concept.
7. **AC7:** At least five headline dashboard measures reconcile to the curated model.
8. **AC8:** A reviewer can reproduce recipient concentration and portfolio-review outputs from the frozen grants register without undocumented manual changes.

## Sign-off Rule
Repository files existing is not enough. The panel must verify these criteria from evidence.

## Evidence Mapping
Map every criterion to requirement(s), artefact(s), test/reconciliation evidence, owner and status.
